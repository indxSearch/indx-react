`TreeCanvas`: a hierarchy as a horizontal tree of pills, a node its name and a count, children fanned out to the right on soft connectors, the chosen node and the path to it lit, the rest collapsed until opened. For a catalogue's categories. Arrow keys move between nodes, right opens and left closes; a node with many children shows the first fifty and a step to the rest; a list view gives the same tree as nested rows for a phone.
